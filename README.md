One sentence explaining the modern internet to a time traveler who has just stepped out of the year 1800 — using only words a person from 1800 could know: a road, a letter, books, a library.

> It is a road to every house on earth, where a letter you write arrives in a blink and more books stand open than any library could hold.

A single comparison carries the whole sentence: a road to every house explains both what the internet is and what it does — letters arrive in a blink, and more books stand open than any library could hold.

## How it works

`main.ts` (Node 22, no dependencies, only `node:fs`) writes the sentence to `/output/entry.txt` with no trailing newline. Before writing, it self-checks:

- the sentence is 1–200 characters (136),
- it is not only white space,
- it is exactly one sentence ending with a period,
- it contains no word coined after 1800 (internet, computer, digital, online, website, email, screen, data, network, video, phone, television).

Run it with:

```sh
node main.ts
```
